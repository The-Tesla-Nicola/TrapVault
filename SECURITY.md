| Version | Supported |
| ------- | --------- |

## Reporting a Vulnerability

Report security vulnerabilities **privately** rather than opening a public issue.

- Email: security@yourdomain.com
- Or use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)

Please include:
- Description of the vulnerability and its impact
- Steps to reproduce
- Affected version / commit

We aim to acknowledge reports within 72 hours and provide a remediation
timeline within 7 days.

## Scope & Responsible Use

This repository contains a **defensive security** platform (honeypot + SIEM +
SOAR). It is intended for:

- Authorized security research
- Defensive detection engineering
- Educational and operational SOC use

Do **not** deploy this tool against systems you do not own or have explicit
permission to monitor.
